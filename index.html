A* Search Algorithm

The AI technique used by this system.

CORE FORMULA
f(n) = g(n) + h(n)

g(n): actual cost from start
h(n): estimated cost to goal

Algorithm Steps

  1. Add the start node to the open list.
  2. Calculate f(n) for available nodes.
  3. Select the node with the smallest f(n).
  4. Expand its neighboring nodes.
  5. Update costs and parent nodes.
  6. Repeat until the destination is reached.
  7. Trace parents to display the route.
